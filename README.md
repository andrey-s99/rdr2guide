# Журнал охотника — RDR2

Справочник крафта для Red Dead Redemption 2: вещи Охотника, Пирсона и Скупщика, костюмы, звери, запасы шкур и список охоты. Работает без интернета и ставится на телефон как приложение.

## Как опубликовать

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь зелёной галочки. После этого приложение доступно по адресу `https://<имя>.github.io/<репозиторий>/`. Откройте его на телефоне в Chrome.
4. В меню Chrome (три точки) выберите **«Добавить на главный экран»** или **«Установить приложение»**. Теперь приложение открывается с главного экрана, в том числе без интернета.

## Как обновить данные

Замените файлы в папке `data/` и сделайте коммит. GitHub соберёт приложение заново, а телефон получит обновление сам при следующем открытии с интернетом. Перед сборкой данные проверяются автоматически: если в них ошибка, сборка остановится и в Actions будет видно, что не так.

## Резервная копия

Прогресс хранится только в телефоне. Чтобы не потерять его, откройте **Настройки → «Сохранить резервную копию»** — скачается файл `rdr2-hunter-backup-ГГГГ-ММ-ДД.json`. Восстановить: **Настройки → «Загрузить резервную копию»** и выберите этот файл.

## Локальный запуск для разработки

```
npm install
npm run dev
```

Другие команды: `npm run test` — тесты, `npm run lint` — проверка кода, `npm run build` — сборка, `npm run icons` — пересоздать иконки из `public/icon.svg`.
