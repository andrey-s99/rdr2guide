# Решения

- Добавлены служебные dev-зависимости для линтера и типов: `@eslint/js`, `eslint-config-prettier`, `globals`, `@types/node` (нужны для flat-config ESLint + Prettier и типов Node в скриптах/конфиге). Для `npm run validate` выбран `tsx`.
- Версия приложения берётся из `package.json` через `define: __APP_VERSION__` в `vite.config.ts`.
- Логика проверки данных вынесена в `src/data/validate.ts` (относительные импорты, без алиаса `@data`), её используют и `scripts/validate-data.ts`, и `tests/data.test.ts`.
- «Сбросить прогресс» (`resetAll`) очищает изготовленное, запасы и цели, но сохраняет настройки (тема, английские названия).
- Запас 0 хранится как отсутствие ключа в `stock`. Возврат материалов при снятии отметки также ограничен 999.
- Короткие названия материалов для тоста и чипсов: для шкур — название животного («Бобр»), для туш и рогов — «<животное> (туша)» / «<животное> (рога)», для остальных (перья, части легендарных, особые) — полное `nameRu`.
- Тост «Костюм: <название>, N частей» — слово «частей» склоняется по числу (часть/части/частей). Строка списания в тосте костюма — сумма по всем отмеченным частям.
- Порядок областей в выпадающем списке сводки: Общее (Всё, Цели), Охотник (всё, все костюмы, 8 категорий в порядке `vendor.categories`), Костюмы (порядок `outfits.json`), Пирсон (всё, сумки, лагерь), Скупщик. Предметы области — в порядке `items.json`, кроме `outfit:<id>` (порядок частей костюма).
- Поиск: «начало слова» — совпадение в начале строки или после любого символа, не являющегося буквой/цифрой; ранжирование по лучшему из `nameRu`/`nameEn`.
- Сообщение о битом сохранении показывается обычным тостом без кнопки «Отменить».
- Шрифты подключаются только подмножествами latin + cyrillic (`@fontsource/<font>/latin-<w>.css`, `cyrillic-<w>.css`), чтобы не тянуть в прекэш лишние файлы.
- Роутер: переключение вкладок и подразделов создаёт запись в истории (push), «назад» в шапке вызывает `history.back()`, а если приложение открыто сразу на карточке (истории внутри приложения нет) — переходит в последний раздел. Глубина истории хранится в `history.state.idx`.
- Прокрутка: при возврате назад/вперёд восстанавливается сохранённая позиция; при обычном переходе (`navigate`) экран открывается сверху. Прокручивается сам документ (шапка и навигация `position: fixed`).
- Нижняя вкладка ведёт на последний открытый подраздел этого раздела (в памяти), иначе на подраздел по умолчанию. На карточках, поиске и настройках подсвечивается последний раздел.
- Иконка вкладки «Звери» — `paw`; для вкладки «Сводка» добавлена своя иконка `ledger` (в списке 10.4 подходящей нет).
- Активная вкладка нижней навигации: иконка на «плашке» цвета `--accent` со светлой иконкой (акцентный цвет текстом на тёмном фоне не проходит по контрасту).
- Добавлены производные токены (не из таблицы 10.1): `--on-accent`, `--paper-muted`, `--paper-rule`, `--paper-ok`, `--paper-warn-bg`, `--vignette`, `--shadow`, `--scrim` — для контраста на «бумаге» карточек в ночной теме.
- Экраны-карточки названы `ItemScreen`, `OutfitScreen`, `AnimalScreen`, `VendorScreen`, чтобы не путать с компонентами (`OutfitCard` и т. п.).
- Строки списков: ссылка на карточку — название предмета, растянутое на всю строку (`::after`), галочка, звезда и значок «данные спорные» лежат поверх неё (не вложены в `<a>`).
- Пометка блокировки (7.2) в строке списка: «Сначала другие X/Y» с иконкой замка.
- Подтверждения — общий `confirm({...}) => Promise<boolean>` и один `<ConfirmHost/>` в `AppShell`; диалог — `role="dialog"` + `aria-modal` (без нативного `<dialog>`, его нет в jsdom). Кнопка по умолчанию «Да» / «Отмена».
- «Данные спорные»: для `medium` — «источники расходятся», для `low` — «данные из одного источника».
- Бейдж зверя при `нужно 0` — «хватает».
- Тип `StatusFilter` и фильтр по статусу — в `src/logic/filters.ts`; выбор фильтра на сессию — `statusFilterSignal(screenKey)` в `src/state/session.ts`.

## M3: Охотник
- Фильтр-чипсы на экране «Охотник → Костюмы» применяются к костюмам целиком: «Не сделано» — костюм не собран; «Готово к крафту» — костюм не собран и для его оставшихся частей всё добыто (итог `units` области `outfit:<id>` равен 0); «Сделано» — костюм собран. По умолчанию «Не сделано», выбор запоминается на сессию.
- На чипсах фильтра показывается число элементов для каждого значения.
- В «Охотник → Предметы» категория, в которой под текущим фильтром нет предметов, скрывается целиком; счётчик «сделано X из Y» в заголовке группы считается по всей категории, без учёта фильтра.
- Тексты пустых состояний: «Здесь пока пусто — всё изготовлено» (предметы, «Не сделано»), «Здесь пока пусто — все костюмы собраны» (костюмы, «Не сделано»), «Пока нет костюмов, для которых всё добыто» / «Пока нет предметов, для которых всё добыто» («Готово к крафту»), «Пока нет собранных костюмов» (костюмы, «Сделано»), «Здесь пока пусто» (остальные случаи).
- В карточке костюма блок «Что нужно добыть» показывает все материалы с `need > 0`, включая уже собранные (они приглушены); строка материала раскрывает «Для чего нужно» только по частям этого костюма. Итог: «Осталось добыть: N шт., K видов материалов». Если всё изготовлено — «Все части изготовлены, добывать ничего не нужно.»
- Подтверждение «Отметить весь костюм»: заголовок «Отметить N частей изготовленными?», текст «Материалы будут списаны из запасов», кнопка «Отметить».
- Снятие отметки в карточке предмета: если при изготовлении что-то списали — диалог «Вернуть списанные материалы в запасы?» со списком «материал: +N»; если ничего не списали — «Снять отметку «изготовлено»?» с пояснением «При изготовлении ничего не списывалось, в запасы ничего не вернётся.» Кнопка подтверждения — «Снять отметку».
- В карточке предмета под названием показываются торговец и категория («Охотник · Шляпы»), цена (если не null) и текущий статус по 7.2; предварительные предметы («Сначала изготовьте: X из Y») — списком ссылок с отметкой изготовленных.

## M4: Пирсон и Скупщик
- Пирсон и Скупщик: у фильтр-чипсов показываются счётчики предметов по каждому статусу.
- Пустые состояния списков зависят от фильтра: «Здесь пока пусто — всё изготовлено» (Не сделано), «Пока ничего нельзя изготовить — не хватает материалов» (Готово к крафту), «Пока ничего не изготовлено» (Сделано).
- «Легенда Востока»: пока предмет заблокирован, показывается пометка «Сначала другие X/6»; после изготовления всех шести сумок — строка «Нужные предметы изготовлены: 6/6».
- Пирсон → Лагерь: порядок групп и счётчик «сделано X из Y» считаются по всем данным; группы, в которых после фильтра не осталось строк, скрываются. Строка предмета дополнительно показывает campSpotRu.
- Внизу экранов Скупщика — кнопка «Сводка по Скупщику» (область fence).
- Карточка торговца: ссылки на подразделы и «Сводка по торговцу» — список строк-ссылок внизу карточки; прогресс «Изготовлено X из Y» — по всем предметам торговца.

## M5: Звери
- Легендарные звери в списке сортируются так: сначала «Не добыт» (шкуры нет в запасах), затем по убыванию «нужно N», затем по `nameRu`.
- Фильтр регионов и переключатель «Только нужные» на экране «Звери» общие для всех трёх вкладок и хранятся в памяти на сессию.
- На карточке зверя блок «Материалы с этого зверя» вынесен под бумажную карточку, на тёмный фон, как в сводке, чтобы использовать общий `MaterialRow`. «Нужно всего / осталось» показывается в формате `MaterialRow`: «нужно X · есть Y» и крупное число «осталось».
- Ссылки в «Карты и гайды»: сначала ссылки зверя, затем `meta.globalMapLinks`; повторяющиеся URL показываются один раз.
- Пустые состояния списка зверей: «Все звери из этого списка уже не нужны» (если всё скрыл переключатель «Только нужные») и «В выбранных регионах таких животных нет».

## M6: Сводка и цели
- Сводка: при смене области или группировки адрес обновляется через `navigate(..., { replace: true })`, без новой записи в истории. Если в адресе нет области или группировки (или они неверные), адрес тоже заменяется на итоговые значения.
- Сводка: в `rdr2-hunter:ui` область и группировка сохраняются только при явном выборе пользователем. Переход по ссылке вида `#/summary?scope=…` сохранённый выбор не меняет.
- Сводка: неизвестная область в адресе заменяется на `all`. Неизвестная группировка заменяется сохранённой или «По зверям».
- Сводка: переключатель «Показывать собранное» хранится в памяти на время сессии, по умолчанию выключен.
- Сводка «По зверям»: группа «Особые предметы» сортируется вместе с остальными группами (по сумме оставшегося, затем по названию). В режиме «По регионам» она всегда последняя.
- Сводка: внутри группы зверя материалы идут в порядке `materials.json`. В режиме «Списком» при равном остатке строки сортируются по `nameRu`.
- Сводка «По регионам»: регионы идут в порядке `regions.json`, регионы без материалов не показываются. Рядом с названием региона — сумма оставшегося («N шт.»).
- Сводка: если цели есть, но всё собрано, показывается «Всё нужное уже добыто». Если все предметы области изготовлены — «Здесь пока пусто — всё изготовлено».
- Сводка: строка итога склоняется по числу: «1 вид материала / 3 вида материалов / 110 видов материалов» и «Изготовлено X из 21 предмета / из 167 предметов».

## M7: Поиск и настройки
- Поиск: результат-материал ведёт на карточку животного, с которого он добывается; особый материал (animalId = null) — на карточку первого предмета (в порядке items.json), в рецепте которого он есть.
- Поиск: поле ввода в шапке (компонент SearchField); запрос хранится в адресе `#/search?q=`, при наборе адрес заменяется (replace), чтобы не засорять историю «назад».
- Поиск: группа без результатов не показывается; в заголовке группы — число найденных (не больше 20 по 7.7).
- Настройки: импорт заменяет состояние целиком, включая настройки темы и английских названий из файла.
- Настройки: сброс прогресса удаляет «изготовлено», запасы и цели; настройки сохраняются (как в resetAll).
- Настройки: после загрузки копии показывается «Резервная копия загружена», после сброса — «Прогресс сброшен»; при ошибке файла — текст ошибки и «Текущий прогресс не изменён.»
- Настройки: источники показаны как адрес без `https://` и `www.`; список спорных предметов раскрывается кнопкой «Показать список».

## M8: Полировка
- Контраст (WCAG AA 4,5:1): декоративные токены из таблицы 10.1 (`--brass`, `--ok`, `--warn`, `--danger`) оставлены как есть для рамок, звёзд и иконок; для текста добавлены варианты `--brass-text`, `--ok-text`, `--warn-text`, `--danger-text` и `--paper-brass-text` (латунный текст на «бумаге»). Ночь: латунь та же, остальные чуть светлее; Бумага: заметно темнее (например, латунный текст `#5f4610` вместо `#8a6a1f`, 5,6:1 на `--bg`).
- Тема «Бумага»: `--text-muted` затемнён с `#6b5b46` до `#5e4d38` — с исходным значением на фоне `--bg` получалось 4,1:1, а 10.1 требует AA. `--paper-ok` затемнён до `#435b1f` (был 4,3:1 на бумаге в ночной теме).
- Счётчик активного фильтр-чипса окрашен цветом текста чипса (приглушённый на подкрашенном фоне давал 3,4:1); бейдж числа целей в шапке — на фоне `--brass-text`.
- Зоны нажатия: чипсы стали 36 px с невидимым расширением до 44 px (у прокручиваемого ряда чипсов добавлен вертикальный отступ, чтобы расширение не обрезалось); поле поиска и кнопка очистки — 44 px; ссылки-источники в настройках — не ниже 44 px; значок «данные спорные» поднят над раскрытой пояснялкой, чтобы она не перекрывала его зону нажатия.
- Повторяющиеся заголовки убраны: «Сводка» и «Обычные/Легендарные звери/Птицы» под шапкой больше не видны (остались скрытыми для экранного диктора, как на экранах Пирсона и Скупщика). На экране поиска скрыта кнопка «Поиск» в шапке — поле уже есть.
- Длинные названия: перенос только между словами (`overflow-wrap: break-word` вместо `anywhere`), чтобы заголовки вроде «Смертельный кувырок» не рвались посреди слова; в строках списков по-прежнему 2 строки и многоточие. Подписи коробочного переключателя («Как в системе») переносятся на вторую строку вместо обрезки; у плейсхолдера поиска — многоточие.
- Английские подзаголовки всегда строчными, даже внутри заголовков, набранных прописными (группы сводки).
- Списки Пирсона и Скупщика растянуты на всю ширину экрана, как у Охотника; заголовки групп лагеря выровнены по краю; «сделано X из Y» в заголовках групп везде строчными.
- Скрытый `<input type="file">` для загрузки копии не считается зоной нажатия: он вызывается кнопкой «Загрузить резервную копию» и убран из порядка табуляции.
