# Решения

- Добавлены служебные dev-зависимости для линтера и типов: `@eslint/js`, `eslint-config-prettier`, `globals`, `@types/node` (нужны для flat-config ESLint + Prettier и типов Node в скриптах/конфиге). Для `npm run validate` выбран `tsx`.
- Версия приложения берётся из `package.json` через `define: __APP_VERSION__` в `vite.config.ts`.
- Логика проверки данных вынесена в `src/data/validate.ts` (относительные импорты, без алиаса `@data`), её используют и `scripts/validate-data.ts`, и `tests/data.test.ts`.
- «Сбросить прогресс» (`resetAll`) очищает изготовленное, запасы и цели, но сохраняет настройки (тема, английские названия).
- Запас 0 хранится как отсутствие ключа в `stock`. Возврат материалов при снятии отметки также ограничен 999.
- Короткие названия материалов для тоста и чипсов: для шкур — название животного («Бобр»), для туш и рогов — «<животное> (туша)» / «<животное> (рога)», для остальных (перья, части легендарных, особые) — полное `nameRu`.
- Тост «Костюм: <название>, N частей» — слово «частей» склоняется по числу (часть/части/частей). Строка списания в тосте костюма — сумма по всем отмеченным частям.
- Порядок областей в выпадающем списке сводки: Общее (Всё, Цели), Охотник (всё, все костюмы, 8 категорий в порядке `vendor.categories`), Костюмы (порядок `outfits.json`), Пирсон (всё, сумки, лагерь), Скупщик. Предметы области — в порядке `items.json`, кроме `outfit:<id>` (порядок частей костюма).
- Поиск: «начало слова» — совпадение в начале строки или после любого символа, не являющегося буквой/цифрой; ранжирование по лучшему из `nameRu`/`nameEn`.
- Сообщение о битом сохранении показывается обычным тостом без кнопки «Отменить».
- Шрифты подключаются только подмножествами latin + cyrillic (`@fontsource/<font>/latin-<w>.css`, `cyrillic-<w>.css`), чтобы не тянуть в прекэш лишние файлы.
- Роутер: переключение вкладок и подразделов создаёт запись в истории (push), «назад» в шапке вызывает `history.back()`, а если приложение открыто сразу на карточке (истории внутри приложения нет) — переходит в последний раздел. Глубина истории хранится в `history.state.idx`.
- Прокрутка: при возврате назад/вперёд восстанавливается сохранённая позиция; при обычном переходе (`navigate`) экран открывается сверху. Прокручивается сам документ (шапка и навигация `position: fixed`).
- Нижняя вкладка ведёт на последний открытый подраздел этого раздела (в памяти), иначе на подраздел по умолчанию. На карточках, поиске и настройках подсвечивается последний раздел.
- Иконка вкладки «Звери» — `paw`; для вкладки «Сводка» добавлена своя иконка `ledger` (в списке 10.4 подходящей нет).
- Активная вкладка нижней навигации: иконка на «плашке» цвета `--accent` со светлой иконкой (акцентный цвет текстом на тёмном фоне не проходит по контрасту).
- Добавлены производные токены (не из таблицы 10.1): `--on-accent`, `--paper-muted`, `--paper-rule`, `--paper-ok`, `--paper-warn-bg`, `--vignette`, `--shadow`, `--scrim` — для контраста на «бумаге» карточек в ночной теме.
- Экраны-карточки названы `ItemScreen`, `OutfitScreen`, `AnimalScreen`, `VendorScreen`, чтобы не путать с компонентами (`OutfitCard` и т. п.).
